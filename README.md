# 🤓 DeepLearning-zero-hero

> From Linear Layers to LLMs and Agents, implemented from scratch with PyTorch.

当前，深度学习领域发展迅速，网络上的相关教程层出不穷。与此同时，各类基础框架和工具库也已经十分完善。在实际开发中，我们往往只需要基于已有代码调用不同的库和模块，再根据需求进行调整，就可以像“搭积木”一样快速完成一个深度学习项目。

这种便利极大地提高了开发效率，但同时也带来了基础不扎实、知识体系不完整的问题。虽然网络上有大量深度学习教程，但很多内容主要停留在对某类算法原理的介绍上，很少进一步深入到具体的代码实现。因此，我们对于许多算法的理解，往往仍停留在较为浅层的概念和印象上。

另一方面，在实际项目中，我们通常直接调用各种成熟的库和模块，却未必真正了解这些模块内部是如何实现的。尤其是在 AI 技术快速发展的今天，新的模型、框架和工具不断出现，我们越来越容易依赖现成的接口，而忽略底层原理。最终，即使完成过许多深度学习项目，我们可能仍然无法从零开始用代码实现一个 Transformer😢。

我认为，在这样一个追求效率、技术快速迭代的时代🤯，我们反而更需要慢下来，去做一些看起来“没有那么高效”、甚至暂时“没有什么用”的事情，例如重新理解一个基础公式，或者亲手实现一个已经有成熟库可以直接调用的模块。因为只有这样，我们才能逐渐建立起更加扎实、系统的知识体系。

本项目正是希望针对当前网络深度学习资源较为零散、原理讲解与代码实现之间存在断层的问题，做出一些尝试。对于深度学习初学者，可以从最基础的线性层开始，在理解数学原理的同时亲手完成代码实现，并逐步学习常见的算法、网络结构和训练策略；对于已经具备一定深度学习项目经验的人，也可以通过重新实现这些基础模块，进一步理解各种组件背后的工作原理，从“会调用”逐渐走向“真正理解”。


项目整体结构如下 👇

DL-zero-hero
│
├── 01-foundations        # 最基础的神经网络组件
│
├── 02-architectures      # 经典与现代模型架构
│
├── 03-training           # 模型训练方法与实践
│
├── 04-llm                # 从 Transformer 到现代 LLM
│
└── 05-agents             # 构建在 LLM 之上的 Agent 系统

🧱 01-foundations：基础组件

这一部分将从最基本的神经网络模块开始，介绍它们背后的原理以及具体的代码实现，包括 Linear、Activation、Normalization、Loss、Attention 等。

目标不仅是知道这些模块“怎么用”，更希望能够理解它们“为什么这样设计”以及“内部是如何实现的”，为后续学习更加复杂的网络结构打好基础。

🏗️ 02-architectures：模型架构

这一部分将介绍常见的经典与现代深度学习模型，并尝试从原理推导到代码实现，包括 CNN、ResNet、RNN、Transformer、SSM 等。

相比直接调用成熟框架中的现成模型，这里更关注模型本身的结构设计与实现细节，希望能够真正理解一个完整的神经网络是如何由基础组件一步步搭建起来的。

🚀 03-training：模型训练

有了模型之后，下一个问题就是：如何把它训练好？

这一部分将围绕模型训练展开，从最基础的 training pipeline 开始，逐步介绍优化、数据处理、训练策略等内容，同时也会涉及一些典型的训练范式与模型，例如对比学习（CLIP）、GAN 等。

🧠 04-llm：从 Transformer 到现代 LLM

这一部分将从 Transformer 出发，逐步走向现代大语言模型（LLM）。

我们会关注 LLM 中的重要模块、训练方式以及模型结构的演变，希望能够回答一个核心问题：今天的大语言模型，究竟是如何从 Transformer 一步步发展而来的？

🤖 05-agents：LLM 之上的 Agent

当我们已经拥有一个强大的 LLM 后，还能在它之上构建什么？

这一部分将关注当前 LLM 的前沿应用，介绍 Agent 系统相关的概念与实现，包括工具调用、记忆、规划、工作流等内容，并尝试理解如何让 LLM 从单纯的“文本生成模型”，逐渐成为能够完成复杂任务的智能系统。

整体上，本项目希望形成一条相对完整的学习路径：

基础组件 → 模型架构 → 模型训练 → 大语言模型 → Agent 系统 ✨

从最基础的一行 Linear 开始，一步步走到今天的 LLM 与 Agent。
